# Screenshot instructions

This repository currently does not contain application screenshots. Capture screenshots only from a real local run; do not create mock UI images or include private credentials and personal data.

Suggested files:

- `screenshots/login.png`
- `screenshots/dashboard.png`
- `screenshots/profile.png`
- `screenshots/project-details.png`
- `screenshots/issue-details.png`
- `screenshots/contribution-heatmap.png`

For a portfolio-quality set, use a test account, crop to the DevSphere window, show meaningful non-sensitive sample data, and include the real contribution heatmap. Add a short caption or alt text for each image in the README.
